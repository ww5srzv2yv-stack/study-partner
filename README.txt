# Study Partner（iPhone向けPWA）

## 含まれる機能
- 参考書の登録、科目別表示、進捗率・問題数・理解度の編集
- 日付別の学習時間・演習数・理解度・振り返り記録
- 今日のタスク
- チャッピー相談用の学習状況コピー
- JSONバックアップ／復元
- オフライン用キャッシュ

## 大切な注意
データは利用中のブラウザの localStorage に保存されます。サーバー同期ではありません。
SafariのWebサイトデータ削除、端末変更などで消える可能性があるため、定期的に「バックアップを書き出す」を使ってください。
チャッピーとの自動会話連携は含まれていません。相談画面から状況をコピーしてChatGPTに貼り付けます。

## 公開方法（HTTPSが必要）
1. このフォルダの中身を、HTTPS対応の静的ホスティング（例：GitHub Pages）にアップロードします。
2. 公開されたURLをiPhoneのSafariで開きます。
3. Safariの共有ボタン →「ホーム画面に追加」→「ホーム画面に追加」を選びます。
4. ホーム画面の Study Partner アイコンから起動します。

GitHub Pagesの場合は、GitHubで新しいリポジトリを作成し、このフォルダ内のファイルをアップロードして、Settings → Pages → Deploy from a branch → main / root を選択します。
公開URLはリポジトリ名などによって決まります。

## 更新
ファイルを更新して再公開すると、Service Workerのキャッシュ名を変更（sw.jsの study-partner-v1 を study-partner-v2 など）すると更新を反映しやすくなります。
